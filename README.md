# SwiftRide - Premium Bus Booking System

SwiftRide is a state-of-the-art, Single Page Application (SPA) designed for a premium bus ticket booking experience. Built with a focus on rich aesthetics, smooth interactions, and a robust feature set.

## ✨ Key Features

- **Premium UI/UX**: Features glassmorphism, dynamic animations, and a modern dark mode.
- **Advanced Booking Flow**: Interactive seat selection, real-time price updates, and a dedicated boarding pass generator.
- **Admin Console**: Context-aware management for buses, users, and coupons with a dynamic action-oriented dashboard.
- **Split Payment System**: Integrated wallet with the ability to split payments between wallet balance and other methods.
- **Multi-Input Form System**: Professional, unified data entry modals for administrative tasks.
- **Referral System**: Shareable referral codes with bonus tracking.
- **Offline Persistence**: Entire application state and database are managed via `localStorage` for seamless offline-capable functionality.

## 🛠️ Technical Stack

- **Frontend**: HTML5, Vanilla JavaScript, CSS3 (Tailwind CSS v3 via CDN)
- **Icons**: Font Awesome 6.4.0
- **Typography**: Inter (UI) & Outfit (Display)
- **Data Layer**: JSON-based mock database with `localStorage` persistence.

## 🚀 Deployment

This project is a Single Page Application. 

### Hosting on GitHub Pages / Netlify:
1. Rename `src/main/webapp/index.jsp` to `index.html`.
2. Remove the Java header line (`<%@ page ... %>`) from the top of the file.
3. Push to GitHub and enable GitHub Pages or link to Netlify.
